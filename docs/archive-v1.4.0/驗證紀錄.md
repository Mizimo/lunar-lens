# Lunar Lens 1.4.0 驗證紀錄

日期：2026-09-09。Max 9.1.4 / macOS；最終原生 DSP 取樣率 48 kHz。原始歌曲不收進 GitHub 或 ZIP。

## 最終版本的檢查

- **96 組軟體回歸通過**：原有路由、行為、事件、觸控、轉場，加上 16 段空間資料、各行為音域、左右辨別、側向可讀性、缺失資料與 UI 控制。
- **低頻 10,000 步逐次回歸通過**：與 1.1 參考的起音決策相同。
- 低頻 detector、原有分析 DSP、事件規則、觸控音訊 DSP 和 MIDI 協定相對 `v1.3.0` 位元一致。低頻僅撤掉視覺上的左右投影，沒有改起音時間、能量比或力度。
- 全部七構圖的低頻形體在相同低頻輸入強度下，不因左右分布而拆開。原有形體寬度和手勢仍可調整整體形狀。
- 在中央較強、側向較弱的中頻對照中，側向可讀性使左右配置的畫面差異增加；原始功率和比例未改，純聚中訊號不會憑空產生侧向成分。
- 窄形體使用面積採樣，避免單點重採樣漏掉細小移動形體。

## 最終原生 Max 校準

使用自製 44 秒、與 DSP 同取樣率的音訊。11 種條件，每種 4 秒；數字取穩定區間的中位數。

| 已知訊號 | 最終結果 |
| --- | --- |
| 同電平、同相 1 kHz | 聚中約 100% |
| 只有左／右 | 對應側約 100% |
| 等電平反相 | 左右各約 50%，聚中 0% |
| 等電平、相差 90° | 左右各約 50%，聚中 0% |
| 同相但右振幅只有左的 55% | 左 76.77%、右 23.23%，聚中 0% |
| 左右獨立白噪音 | 左右約各 50%，聚中中位數 0% |
| 左低、中央 1 kHz、右中頻 | 每個音域保持自己的空間配置 |
| 上述交換左右 | 測量位置隨之交換，低頻視覺仍為整體 |
| 1.1 kHz 左、1 kHz 聚中、1.4 kHz 右 | 同一粗音域內仍保留三份功率 |
| 靜音 | 退黑，沒有殘留頻譜活動 |

這些條件是校準案例，不是樂器分離的準確率評估。最終記錄共 **1426 幀**；[完整結果與原生生成檔雜湊](stereo-calibration.json)。

## 限制

- 聚中是近等電平和高度同相的證據，不是中央聲部或人聲分離。真正居中的聲音若被其他聲音遮住，可能沒有足夠證據；空白的聚中柱不代表沒有中央音源。
- 同一訊號複製到兩邊，與單一居中音源，可以有相同的錄音波形，無法由此恢復真實聲源數量。
- 混響、雙軌、相位旋轉會影響空間估計。左右有內容不意味存在兩件樂器。
- 80 ms 功率平滑和 FFT 窗有時間代價，快速聲像會被平滑；低頻起音仍走原有獨立路徑。
- 沒有因為校準通過就宣稱複雜混音的 IMPACT 或聲部分離準確率提高。
- Launchpad 本輪未連接實機；協定、預覽與 RGB 範圍經軟體驗證，不宣稱量到實體亮度或延遲。

## 重現

```sh
npm run build
npm test
# 開啟主 patch 及本機測試橋接 tmp/runtime-control.maxpat：
python3 scripts/check-stereo.py
node scripts/render-stereo-review.mjs
python3 scripts/render-stereo-review.py
# 全曲量測工具（不要在使用者正在試聽時覆蓋播放）：
python3 scripts/run-song-check.py /path/to/recording.mp3 localcheck
python3 scripts/verify-song-trace.py localcheck
node scripts/review-stereo-song.mjs localcheck
npm run package
python3 scripts/verify-release.py
```

`verify-final-spatial.py` 驗證本輪保留在本機 tmp 的最終操作記錄及 Git 基線；不偽造不存在的歌曲真值。原始音訊、測試橋接與大型 trace 均不進封裝。Pillow／NumPy／ffmpeg 只供選用驗證，正式 Max 專案沒有這些執行依賴。
