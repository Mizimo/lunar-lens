## 實際 Max 音訊

以 `scripts/make-fixture.py` 建立已知測試訊號，再由主 Patch 正常 `loadfile`、`sfplay~`、Gen 分析及 `sfrecord~` 運行；不是以離線模型假裝 Max 輸出。

- 80 Hz / 800 Hz / 8 kHz 正確分別主導低 / 中 / 高頻。
- 左右反相 440 Hz 仍讀到約 0.128 RMS；寬度約 0.974。
- 同相訊號寬度回到約 0.002。
- 120 BPM 脈衝鎖定為 120 BPM，最高信心約 0.713；靜音後退回未鎖定。
- 實際錄音 48 kHz、30.443 秒、全數值有限，峰值約 −13.35 dBFS。
- 與輸入在同一採樣率下對齊後，相關度 0.9989。檔案為 44.1 kHz、DSP 為 48 kHz，有正常採樣率轉換；不宣稱 bit-perfect。

測試發現並修正了「DSP 尚未啟動就先建立錄音檔」可能沿用錯誤採樣率標頭的問題。錄音程序現在先啟動 DSP，再開 WAV，最後開始寫入。修正版實際輸出標頭為 48 kHz。

詳細結果：`actual-audio-validation.json`。驗證腳本 `scripts/verify-audio.py` 需要 numpy 與 ffmpeg，運行本專案不需要它們。

## 互動與效果

為避免實體 MIDI 和逐 byte 注入在同一解析器交錯，錄音量測階段先斷開硬體，用與 GUI / 硬體共用的 pad、pressure、padup 處理函數產生固定手勢。

- 播放持續時，觸點數依序 1 → 2 → 0。
- 第一個觸點壓力設到 127，總效果強度為 0.5；兩個觸點約 0.943；放開為 0。
- 相對乾音的 RMS 誤差：觸控前約 0.009；按住時約 0.222；放開後約 0.013，顯示效果確實加入並釋放。
- 10.72 秒原生效果實錄，峰值約 −19.06 dBFS，全部有限值。
- 本機 **FabFilter Pro-R 2 VST3** 成功回報輸入 / 輸出及效果器類型，啟用後完成 4.47 秒實錄，峰值約 −19.89 dBFS；測試後回到 BYPASS。
- Blackout 實際狀態的 192 個預覽 RGB 值全為 0。

詳細結果：`actual-interaction-validation.json`。AU 由同一個 Max `vst~` 宿主支援，本次未逐個測試本機所有 AU / VST3。

另在 Max 實際測試：單聲道檔案複製成兩聲道，左右輸出最大差為 0；MP3 載入；seek 至 25% 後持續播放；Pause 停在同一位置；Restart 回到開頭；結束播放保留 EOF 位置；更換檔案回到停止狀態。相關數值見 `actual-transport-validation.json`。
