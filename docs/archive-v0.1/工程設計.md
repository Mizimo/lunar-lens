# 工程設計

## 核心限制

所有曲目統一邏輯。任何分析或視覺函數都不接收曲名、歌曲長度、歌詞、小節、預先排好的事件或作品 ID。播放進度僅用於播放器顯示和 seek。Demo 的入口只是 `loadfile()`。

## 訊號路徑

```
sfplay~ / adc~ → source gain ┬→ gen~ lens_analysis → 7 snapshots → LensFeatures
                            │                                    ↓
                            │                     LensVisual ← MIDI / 滑鼠手勢
                            │                       ↓            ↓
                            │                      JSUI       MK3 RGB SysEx
                            └→ gen~ lens_fx → 可選 vst~ → master → clip guard
                                                                  ├→ sfrecord~
                                                                  └→ monitor → dac~
```

MSP 分頻和能量整流按音訊取樣率執行；同一個 `qmetro 20` 以右到左 trigger 更新七個 snapshot，最後才由 pack 輸出一個完整特徵幀。JS 分析不在 MSP 音訊執行緒中运行。畫面和 USB 燈光每 50 ms 更新，觸點會立即請求一幀。

左右聲道先各自計算頻帶能量再平均，避免反相音訊被先行 mono sum 抵消。RMS 指数窗口 12 ms；峰值保持約 150 ms。Mid/Side RMS 分開計算，再平滑其比例。

自動參考音量快速上升、緩慢下降，設有最小值，靜音時不向上拉增益。力度、起音、幾秒鐘的能量變化分別控制不同視覺時間尺度。音訊停止或失去更新時，特徵會衰減，不能保持虛假的 pulse。

週期估計先把最多 8 秒的 novelty 重採樣到 50 Hz，再做約 50–176 BPM 的自相關搜尋。既有速度有小幅連續性偏好，信心低於 0.48 時不輸出 pulse。這是節奏估计而非樂譜轉錄，保留半拍 / 倍拍歧義。

## 視覺

月體、軌道、波浪、雙光及少量星點共享同一特徵幀。自動模式使用連續形態權重，手動選擇也以 2.4 秒平滑過渡。沒有歌曲場景清單。

手指位置建立吸引點，按下產生波紋；壓力控制吸引強度和局部暖光。放開移除吸引力，波紋和粒子自然消失。凍結只保存背景及粒子運動，不凍結手指回饋。

RGB 只使用冷月光、淡紫與克制暖色；全畫面有光量預算，單純提高錄音音量不會點亮整片彩虹。近黑輸出量化至 0，避免暗部一直發灰。GUI 與硬體使用同一組 192 個 RGB 值；GUI 額外做顯示 gamma，不能當成硬體亮度的光度測量。

## 音訊效果與播放器

播放器速度固定 1；不使用 swing、量化、MIDI 重奏、跟隨估計 BPM 的 time stretch。分析位於所有效果器和 master 之前，所以觸控效果或音量調整不會反過來製造假起音。

原生效果：送入效果的音訊先按觸點高度濾色，再进入 310/430 ms 交叉延遲及四線阻尼 FDN。觸點横向位置控制 FDN 衰減。效果量以 80 ms 平滑；無觸點或效果關閉時恢復 dry。反饋增益保持低於 1。

外掛僅為可選效果器，成功回報輸入 / 輸出以及非 synth 後才可啟用。默認 native / dry。插件可能產生額外延遲，這版不做插件延遲補償；要求最緊密的即時光聲關係時，可保持 BYPASS。

錄音先啟動 DSP，再建立 WAV，再開始寫入，避免 DSP 原本關閉時以舊採樣率建立檔頭。錄音為效果後、監聽前的 float32 立體聲。輸出有 ±0.98 ceiling，正常素材 / 預設音量不觸及；它是保護，不是 mastering limiter。

## 裝置協定

採用 [Novation Pro MK3 Programmer Reference](https://fael-downloads-prod.focusrite.com/customer/prod/s3fs-public/downloads/LPP3_prog_ref_guide_200415.pdf)。使用 LPProMK3 MIDI 端口；不使用 DIN / DAW 端口。

- SysEx header：`F0 00 20 29 02 0E`。
- Programmer Mode：`F0 00 20 29 02 0E 0E 01 F7`。
- RGB：命令 `03`，每格 `03 index red green blue`，各色 0–127。
- 8×8 左下角 index 11；`index = 11 + x + 10*y`，x、y 為 0–7。
- Note On velocity 0 與 Note Off 都釋放觸點；接受 running status、poly aftertouch、channel pressure，忽略穿插的 MIDI real-time bytes。
- 連接後必須同時確認型號 inquiry 與 layout 17。實機本次回覆 family byte 35，亦接受手冊所載 19。
- 只送出有改變的 LED；定期查詢 layout，失去回覆後釋放持續手勢。
- 歸還設備 / 關閉主 Patch 時先 blackout，再回 Live 與 Note layout。

## 邊界

目前不是人聲 / 樂器辨識器，也不宣稱理解情緒或歌詞；「低、中、高」是頻帶能量。此版本沒有播放清單、離線整曲分析、段落辨識和錄影輸出。

值得繼續改善的是多種真實錄音下的 pulse 信心與半拍判斷，以及在真實 Launchpad 上調整壓力曲線、暗部 gamma 和光跡長度。這些都應繼續使用同一套曲目無關的邏輯。
