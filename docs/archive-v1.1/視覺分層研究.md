## 人聲與 Pad

頻率範圍只能描述聲音落在哪裡，無法描述它正在做什麼。1.1 觀察中頻子帶的相對形狀、短時振幅調制、起音和近期能量底層。共同漸強在頻帶比例中抵消，穩定底層可以延續；音節式變化形成前景活動。

前景和鋪陳並非 `x` 與 `1-x`。兩層可同時活躍。用相同 440 / 660 / 1100 Hz 音域建立穩定、短促、疊加三種原創訊號，再透過 Max 原生 DSP 比較，見 behaviour-validation.json。

這是因果式行為估計，無法知道歌詞或確定音源。長母音、顫音、琶音合成器、失真吉他都可能跨兩層。下一步若要判斷「這條前景確實是人聲」，值得用獨立人聲與伴奏的已知音軌驗收，再評估統一的來源分離前端；每首歌仍使用同一流程。

## Impact

新建獨立可調帶通，讓用戶控制中心範圍與 bandwidth。自適應只調整背景門檻，避免頻段自動漂移把角色換掉。頻率設定顯示在主畫面，跨界受到保護，調整期間抑制假事件。

原生測試曾發現慢低音漸強與 300 Hz 帶外短音仍會觸發。提高最小上升速度及最低頻段佔比後，以相同訊號重測：8 次 85 Hz 短擊全部觸發、慢漸強 0 次、預設頻段下 300 Hz 短擊 0 次；提高上限到 380 Hz 後，同樣的 6 次 300 Hz 短擊全部觸發。這只是已知訊號的結果，不能推算商業錄音的準確率。

## 視覺驗收原則

同一音訊、同一時刻並排六种構圖；固定一套配色再比較灰階幾何。每一種構圖仍要有低頻形體、前景、鋪陳與短事件。允許不同構圖把它們放到不同位置。稀疏與暗部由幾何、包絡、各層光量預算控制，安靜後完全歸黑。

觸控先確認乾濕路徑，量測按住／放開前後的差異，再提供錄音試聽。數值變化和通過測試不代表所有人都覺得好聽；實機主觀視聽仍是後續最有價值的比較。
