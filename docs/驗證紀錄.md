# Lunar Lens 1.4.1 驗證紀錄

2026-09-09，Max 9.1.4 / macOS。此版恢復六構圖原始視覺，並改善保留的「三域」。音訊測量和低頻判定沿用已接受版本。

## 原始視覺的回歸

以 Git `v1.3.0` 的 `lens_visual.js` 作凍結參考，只調整測試檔的模組路徑。

- 六構圖 × 六種獨看狀態 × 100 幀，共 **3,600 幀 RGB 完全相同**。涵蓋 PHRASE 軌跡、寬度、殘影、事件、觸控、凍結及 Blackout。
- 將最終實曲特徵送入兩份渲染器，六構圖共 **22,986 幀 RGB 完全相同**。這次比對原始視覺程式，包含重力 PHRASE 的形體，不只是改變中央能量。
- 三域是刻意保留並重新設計的第七構圖，不要求與舊版相同。

[實曲回歸結果](visual-rollback-validation.json) · [同幀畫面對照](../media/visual-rollback.png)

## 三域可讀性

自動檢查十個音域分別進入不同格子；左青、中琥珀、右桃紅；相鄰格不再複製同一數值。強低頻不會改寫中高頻亮度參考，三側仍共用同一刻度。原生 Max 畫面亦確認測量與顯示位置對應。

一般軟體測試 **97 組通過**，另有上述 3,600 幀原視覺回歸及 **10,000 次低頻判定與 1.1 基線完全一致**。五行為控制、路由、觸控、事件、轉場、靜音、RGB 範圍與封裝重建均涵蓋在檢查中。

## 最終原生運行

以使用者當前的 `colorful (feat. ほとけ)_spotdown.org.mp3` 原速播放記錄 **124.005 秒 / 3,831 幀**，沒有將此段稱為全曲測試。測量有效、RGB 範圍通過，Max 的三域配色及十格音域分布已實際顯示。

| 指標 | 結果 |
| --- | --- |
| 平均畫面間隔 | 32.38 ms |
| P99 畫面間隔 | 45.00 ms |
| 最長畫面間隔 | 124.00 ms |
| 圖形計算 P99 | 約 1 ms（毫秒時鐘） |

這些是程式排程資料，不是音訊到實體燈光的延遲。[完整記錄與生成檔雜湊](native-visual-141-validation.json)

低頻分析、嚴格聲場 DSP、55 值匯流排、測量模型、事件、觸控 DSP、MIDI 協定與 `v1.4.0` 逐檔一致。保留的 [1.4.0 嚴格聲場校準](stereo-calibration.json) 是這條未變更測量路徑的歷史證據，不標成新的測量算法評估。

本輪早期的《Blossoms》記錄混入使用者換曲，不作為最終單曲／全曲證據；最終 trace 已逐幀記錄來源檔名。原始歌曲和 trace 不上傳或封裝。

## 重現與限制

```sh
npm run build
npm test
# Max 主補丁及本機 QA bridge 開啟後，可記錄當前音訊：
python3 scripts/control.py capturefile /absolute/path/to/trace.jsonl
python3 scripts/control.py capturestop
node scripts/verify-composition-rollback.mjs /absolute/path/to/trace.jsonl
python3 scripts/render-rollback-review.py
npm run package
python3 scripts/verify-release.py
```

回歸圖腳本需要至少 15 秒實曲記錄。Pillow／NumPy／ffmpeg 是選用驗證工具，正式 Max 專案不依賴它們。Launchpad 本輪未接實機；沒有聲源分離、複雜混音底鼓準確率或實體 LED 延遲的新結論。1.4.0 的完整驗證紀錄保留於 `archive-v1.4.0/`。
