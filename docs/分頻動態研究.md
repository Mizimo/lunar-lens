# 分頻動態與低頻回滾 · 1.2.1

1.2 的合成起音測試通過，但使用者在《Blossoms》的複雜編曲與混音中確認低頻誤觸明顯增加。因此 1.2 低頻偵測沒有達到音樂需求，1.2.1 恢復 1.1 的完整觸發判斷。

## 本次決定

低頻恢復 fast/slow > 1.35、原本的短時 log 能量上升量、75 次讀值的平均／標準差門檻、ratio < 1.025 的重新準備條件與最短間隔。移除放寬到 1.01 以及短擊補回。八個固定頻段的獨立動態、已接受事件的連續力度、六種構圖與快速預覽保留。

恢復舊判斷也恢復了它的限制：持續低音上的小重音可能不到 1.35，密度變化仍會影響低頻門檻。本次優先回到使用者實際聽感較可靠的行為。所有曲目仍共用同一套邏輯。

## 實驗設計的修正

合成脈衝能驗證門檻邊界、事件數、時間排程與特定干擾條件，但不能重現真實音色、相位疊加、母帶壓縮及編曲語義。全曲跑完、觸發變少、合成鼓點全對，都不能單獨證明底鼓辨識較準。

本輪分開驗證回滾正確性與運行穩定性：把相同混音特徵交給 1.1、1.2 與回滾版，比對低頻決策及保留的八段資料；再由 Max 原速重播《Blossoms》確認完整播放與合法 RGB。沒有人工逐拍標註，所以不報真實錄音的 precision／recall。

後續真正值得比較的新方法，需要先建立少量人工標註的真實混音片段，記錄重要衝擊、容易誤觸的非衝擊、強弱與可接受偏時；涵蓋不同密度與段落轉換，並另留曲目驗證泛化。可比較能量比、較細頻譜起音或通用分離前端的取捨，再決定是否替換目前預設。
