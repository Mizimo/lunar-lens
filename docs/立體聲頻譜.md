# 左／中／右頻譜與空間映射 · 1.4

原有全頻寬度、左右能量平衡只有一個數字。當低音在左、高音在右而總能量相近時，整體平衡接近零；先加總左右功率的頻譜也無法再找回各音域的位置。

1.4 在 FFT 的每個 bin 保留左右功率和有符號的交叉功率，先估計空間成分，再累積至 16 個音域。相同總能量下，不同頻率的左右配置不會互相抵消。舊低頻 IMPACT 分析和事件決策不經這條路徑。

## 如何看與調整

左側 **左 / 中 / 右**，或 **行為 / 事件 → 聲場頻譜**，開啟三份中高頻頻譜。每份由左至右是 280 Hz–16 kHz 的 10 個音域，三圖使用同一個參考峰值及平方根顯示壓縮。安靜的一側不會被獨立放大；這是相對功率顯示，不是 dBFS 電平表。

- **L 左側（青色）**：未歸入聚中的左側功率。
- **C 聚中線索（琥珀色）**：左右電平接近，且高度同相一致的功率估計。
- **R 右側（桃紅色）**：未歸入聚中的右側功率。

「左右都有」不能作為聚中的充分條件。原有正相關共同功率過於寬鬆；本版增加了嚴格的電平平衡與相位一致性判斷。高度相關但明顯偏左的訊號、等電平但不同相位或獨立的左右訊號，都不應大量落入聚中。

**IMPACT 與 BODY 不做左／中／右投影**，始終是一個完整的低頻重量和衝擊。原始分析仍保留低音域的左右資料，但不把低頻拆成三個形體。下方介面將這兩個行為標示為「整體重量／不分左右」。

另外三條比例對應 PHRASE、BED、DETAIL，選取各自行為的分析音域。前景偏重變動的功率，鋪陳偏重持續的功率，因此同在中頻也可以有不同位置。比例條顯示原始估計，不受下面的視覺加強改寫。

**聲場位置** 預設 85%，控制原有六個構圖中，中高頻各層依空間成分定位的程度；0% 可比較原構圖。**側向細節** 預設 65%，對弱側向成分作視覺動態壓縮，並縮窄中頻形體、拉開側向位置，讓中央較強時兩邊仍可辨認。0% 關閉加強。此參數不改真實功率、音訊或事件數。

窄形體使用面積積分投影，避免一個移動的中頻亮點剛好落在 LED 採樣點之間而消失。原有「形體寬度」仍調整每層尺度；這與左右位置是兩回事。

新增 **聲場／三域** 構圖：下方三行是一個完整低頻基座；上方中高頻分左、聚中、右三列並保留暗縫。相對強弱仍來自同一量測；側向細節控制顯示壓縮。原有低頻 IMPACT 在基座短促亮起。此頻譜構圖不受「聲場位置」關閉，因為它直接顯示頻譜位置。

右側六個硬體場景鍵仍選原有六構圖；第七構圖在 Max 選擇，Launchpad 同步顯示。觸控、轉場、凍結及 Blackout 繼續工作。

## 計算契約

`pfft~ 2048 4`，窗 2048 samples、hop 512 samples。在 48 kHz 時，bin 間距約 23.4 Hz。低頻的細分顯示不代表具有任意精細的頻率分辨率。

對每個複數 bin 的 L 和 R，分別對 `|L|²`、`|R|²` 和 `Re(L × conjugate(R))` 作 80 ms 指數平滑，得到 `PL, PR, X`：

```text
coherent = clamp(X / sqrt(PL * PR), 0, 1)
balance  = min(PL, PR) / max(PL, PR)
phaseGate = smoothstep(0.85, 0.98, coherent)
levelGate = smoothstep(0.70, 0.95, balance)
common   = min(PL, PR) * phaseGate * levelGate
L_side   = PL - common
C_shared = 2 * common
R_side   = PR - common
```

因此三者均非負，總和等於左右總功率；原始左右功率可分別以 `L_side + C_shared/2`、`R_side + C_shared/2` 還原。反相的部分不算聚中線索，會保留在兩側。這個公式是本專案的可解釋估計，沒有宣稱為聲源分離演算法。

必須先逐 bin 分解再合成音域，否則同一個粗音域裡分別在兩側的不同音符會被混在一起。交叉功率先平滑再取正值，可減少獨立左右噪音偶然同相時被大量誤算成中央。

16 個區間邊界（Hz）：
`30, 50, 70, 100, 140, 200, 280, 410, 600, 950, 1500, 2300, 3500, 5100, 7500, 11000, 16000`。

- Gen 輸出前 7 項保留原頻譜描述量和幀序號；後 48 項是 16 × L/C/R 相對 FFT 功率（低頻僅保留在測量層）。55 個值同幀鎖存、冷入口先讀。
- 實際 DSP sample rate 從 `dspstate~ → hostRate` 傳入，不能用音檔取樣率或假設 pfft 內部 samplerate 等於外部。
- `LensMeasurements.schemaVersion = 2` 新增 `stereoSpectrum`，含單位、邊界、有效性、總功率、每段 `power / steadyPower / movingPower`。後兩者由 650 ms 平滑參考形成，不是分離音軌。
- `LensPresentation` 按行為音域加權成五組比例；PHRASE 使用 18% 當前功率 + 82% 高於慢參考的變動量，BED 使用當前與慢參考的較小值。
- `LensVisual` 只接呈現比例與八行分布，不自行讀音訊或分析 FFT。`spatialAmount`、`spatialContrast` 與事件份量獨立。
- 超過 180 ms 沒有新 FFT 幀時資料失效；不沿用過時的頻譜。停止、換曲和 seek 清除 JS 歷史。

## 限制與參考

這不是「左樂器／中央人聲／右樂器」分離。同一音訊等電平、同相複製到兩邊，與單一居中音源可以形成相同的立體聲波形；系統無法由此判定真實聲源數量。相同音高的聲源重疊、雙軌錄音、混響、相位旋轉和立體聲處理都會影響結果。去相關的寬廣聲音通常分布在兩側，未必存在兩件不同樂器；嚴格門檻減少了獨立左右噪音被吸入聚中的情況；詳細校準數值見本輪驗證。

不能直接把 Mid 當成孤立中央音軌：硬偏到一側的聲音也同時出現在 M 和 S。這也是本版使用明確的聚中成分估計與殘餘功率，而不把 `L+R` 標成人聲的原因。[iZotope：Mid/Side 常見誤解](https://www.izotope.com/community/blog/8-common-mistakes-in-mid-side-mixing)

空間測量有 FFT 窗和 80 ms 平滑，快速聲像變化會被平滑；它不是 sample-accurate 定位。低頻 IMPACT 仍用原有獨立能量比判斷並立即請求畫面，沒有為了聲場測量而等待 FFT。第三方效果器／輸出裝置的延遲不在本次補償範圍。
