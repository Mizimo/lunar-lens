# 立體聲測量與三域 · 1.4.1

六種原有構圖恢復 1.3 的視覺程式：重力的 PHRASE 軌跡、寬度、殘影、單一形體取樣、事件位移都保留，不再把它們複製到左／中／右。三域獨立呈現空間分布；右側測量頁繼續保留嚴格聚中判斷。

## 三域怎麼看

- 左兩列是青色，中央兩列是琥珀色，右兩列是桃紅色；兩道暗縫分開位置。
- 上方五行中，每側十格分別對應測量頁的十個音域。相鄰兩格不再重複顯示同一數值。
- 下方三行是完整低頻基座，IMPACT 仍整體亮起，不分左右。
- 三側共用一個中高頻功率參考。沒有分別放大安靜的一側，強低頻也不會壓暗中高頻。
- 亮度只從相對頻譜功率映射一次；不再額外乘上全曲慢能量，也不套用原先細節層過低的亮度預算。全畫面光量上限仍保留。
- 殘影縮短，避免頻譜差異累積成三片相似色塊。安靜時退黑，觸控、轉場、凍結和 Blackout 照常工作。

每側從下向上讀；每行由左至右：

| 中高頻行 | 左格 | 右格 |
| --- | --- | --- |
| 最低行 | 280–410 Hz | 410–600 Hz |
| 第二行 | 600–950 Hz | 950–1500 Hz |
| 第三行 | 1500–2300 Hz | 2300–3500 Hz |
| 第四行 | 3500–5100 Hz | 5100–7500 Hz |
| 最高行 | 7500–11000 Hz | 11000–16000 Hz |

**三域細節可見度** 對三側使用相同顯示壓縮，不改測量或起音門檻。三域的中高頻顏色固定標示位置；配色選擇仍影響低頻和其餘六構圖。三域格子固定代表音域，形體寬度用於另外六構圖；行為的增益、延續和獨看仍能調整三域對應層。原來用來複製六構圖的「聲場位置」滑桿已移除。

## 右側測量圖

三份圖表共用功率參考及平方根顯示壓縮，280 Hz–16 kHz 各十格。L／R 是未歸入聚中的殘餘功率，C 是近等電平且高度同相的聚中線索。下方 PHRASE、BED、DETAIL 比例是行為所選音域的測量；IMPACT／BODY 標示為整體重量。

PHRASE 偏重變動，BED 偏重持續，這不是人聲與 Pad 分離。固定頻譜格顯示音域分布，行為比例則顯示時間特性；兩者不必相等。

## 測量契約

沿用 1.4.0 的 DSP，`pfft~ 2048 4`，hop 512 samples。真實 host sample rate 從 `dspstate~` 傳入。每個 bin 的左右功率與有符號交叉功率先平滑 80 ms，再拆分，最後加總成十六個音域：

```text
coherent = clamp(X / sqrt(PL * PR), 0, 1)
balance = min(PL, PR) / max(PL, PR)
common = min(PL, PR) * smoothstep(.85, .98, coherent)
                         * smoothstep(.70, .95, balance)
L = PL - common
C = 2 * common
R = PR - common
```

L+C+R 等於左右總功率。反相、相差 90 度或明顯偏向一側的訊號不應大量進入聚中。「兩邊都有」不是聚中的充分條件。

55 值 FFT 匯流排保留原 7 項描述量／序號和 16×3 項功率，同幀鎖存。`LensMeasurements.schemaVersion=2` 的 `stereoSpectrum` 保持原單位、有效性和 650 ms 持續／變動參考。180 ms 無新幀即失效。

`LensPresentation.cells` 只把嚴格中高頻功率轉成十格×三側的顯示值。`LensVisual` 的六構圖不使用這些格子；三域才使用。音訊、IMPACT、事件和互動引擎不因這次視覺修正改動。

## 限制

這不是聲源或樂器分離。同相等電平複製的訊號與單一中央音源可以形成同一波形；混響、雙軌、相位處理會影響估計。聚中空白不代表歌曲沒有中央音源。FFT 窗和 80 ms 平滑有時間代價，低頻 IMPACT 仍走原獨立起音路徑。
