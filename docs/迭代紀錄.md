# 迭代紀錄

## 1.3.0

- 六構圖切換增加 0–3 秒背景轉場，支援轉場中再次切換，低頻起音及觸控保持即時。
- 新增立體聲 FFT 頻譜形狀、0.4／3 秒能量、左右相關／平衡與過零率測量。
- 新增帶有時間、強度、依據、啟發式信心的事件流；觀察行為進退、音色、累積／釋放與結構變化候選。
- 分離測量、行為、事件、呈現、轉場與交互模組；既有輸出保留相容轉接。
- 操作入口改為五個聲音行為，各有響應、份量、寬度、延續和分析音域。
- 新建私人 GitHub 倉庫，保留 1.2.1 基線及可重建的版本，附軟體回歸 CI 範本（目前憑證缺 workflow 權限，未啟用）。
- 低頻判斷及原有分析 DSP、聲音效果、MIDI 協定不變。

## 1.2.1

依使用者在《Blossoms》中的回饋，低頻 IMPACT 恢復 1.1 的 1.35 能量比判斷，保留 1.2 的其他頻帶、力度、視覺和介面加速。合成脈衝測試不再當作複雜混音的識別準確率證據。


## 1.4.0 · 每個音域自己的左右位置

新增逐 FFT bin 的左右功率與正相關共同功率估計，累積成 16 音域 × L/C/R。保留反相及兩側不同頻率，不再依靠一個全頻 balance 代表配器位置。三頻譜使用共同刻度；五行為的空間比例依各自音域和變動／持續特性形成。原有六構圖加上分層投影與獨立映射份量，第七構圖直接呈現三列頻譜。

未更改低頻 detector、既有事件規則、音訊效果及 MIDI 協定。此功能是空間／聲音行為估計，不是樂器或人聲音軌分離。加入原生 Max 聲場校準、軟體回歸及實曲運行檢查。


本輪試聽後補充：中頻側向形體分開、增加「側向細節」顯示壓縮與面積採樣，避免細點被稀疏 LED 漏掉。聚中判斷改為嚴格的近等電平＋高度同相證據，避免「兩側都有」直接變成中央；低頻在全部構圖保持單一完整形體。測量與視覺加強的數值分開。
