# 迭代紀錄

## 1.3.0

- 六構圖切換增加 0–3 秒背景轉場，支援轉場中再次切換，低頻起音及觸控保持即時。
- 新增立體聲 FFT 頻譜形狀、0.4／3 秒能量、左右相關／平衡與過零率測量。
- 新增帶有時間、強度、依據、啟發式信心的事件流；觀察行為進退、音色、累積／釋放與結構變化候選。
- 分離測量、行為、事件、呈現、轉場與交互模組；既有輸出保留相容轉接。
- 操作入口改為五個聲音行為，各有響應、份量、寬度、延續和分析音域。
- 新建私人 GitHub 倉庫，保留 1.2.1 基線及可重建的版本，附軟體回歸 CI 範本（目前憑證缺 workflow 權限，未啟用）。
- 低頻判斷及原有分析 DSP、聲音效果、MIDI 協定不變。

## 1.2.1

依使用者在《Blossoms》中的回饋，低頻 IMPACT 恢復 1.1 的 1.35 能量比判斷，保留 1.2 的其他頻帶、力度、視覺和介面加速。合成脈衝測試不再當作複雜混音的識別準確率證據。
