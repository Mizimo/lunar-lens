# Lunar Lens 1.3 工程設計

音頻播放及測量、行為估計、事件判斷、呈現和交互各有獨立來源檔案。Max 主 patch 負責接線，控制器負責轉接與時鐘。

```text
sfplay~ / adc~ ─┬─ gen~ lens_analysis → 原有低頻／八段起音
               ├─ gen~ lens_context → 長短能量、立體聲、過零
               ├─ pfft~ lens_spectral → 立體聲 FFT 描述量
               └─ gen~ lens_fx → 可選 vst~ → Master → 音訊

LensMeasurements → LensFeatures / LensBehaviours → LensEvents
                                                 ↓
                                          LensPresentation
                                                 ↓
                                      LensVisual + LensTransition
                                                 ↓
                                        Preview / Launchpad RGB

滑鼠 / MIDI → LensInteraction → 視覺位置、壓力 / 觸控聲音效果
```

## 檔案責任

| 檔案 | 唯一主要責任 |
| --- | --- |
| scripts/analysis-source.mjs | 產生原有低頻與八段分析 DSP；本輪保持 1.2.1 位元一致 |
| code/lens_context.genexpr | 不經效果器的長短能量與左右測量 |
| code/lens_spectral.genexpr | FFT 幀上的頻譜描述量計算 |
| code/lens_measurements.js | 命名量測、單位、有效性；無視覺規則 |
| code/lens_features.js | 相容的原有低頻／八段起音及預設行為估計；本輪未改 |
| code/lens_behaviours.js | 五行為獨立響應與自訂音域 |
| code/lens_events.js | 進入／退去、變化候選、密度、事件 ID 與信心 |
| code/lens_interaction.js | 按壓、釋放、壓力、加權觸點 |
| code/lens_presentation.js | 事件只消費一次、轉為呈現狀態 |
| code/lens_visual.js | 六種構圖、五層空間與配色 |
| code/lens_transition.js | 背景轉場、連續改目標 |
| code/lens_protocol.js | Launchpad Pro MK3 MIDI／SysEx，未改 |
| scripts/controller-core.js | Max 時鐘、資料轉接、音訊／MIDI 路由、控制命令 |
| code/lens_ui.js / lens_grid.js | 低頻率控制面板／快速 8×8 預覽 |

目前保留 `LensFeatures` 的既有輸出欄位作為相容橋梁，避免把低頻回滾與架構遷移混成一次不可比較的重寫。新的測量與事件都有 schemaVersion，可以單独儲存與重播。

## 兩種分析時間尺度

原有 24 個 DSP 值仍以 `qmetro 20` 收集，冷入口先更新。FFT 和 contextual 列表在同一輪先送到控制器，但 FFT 使用完整窗；它們是不同時間尺度，不能宣稱所有量測具有同樣延遲。

低頻起音仍在接受當下立即請求畫面，之後回到 33 ms 畫面節奏。背景轉場不阻塞起音或按壓。UI 使用 V8／Dict 傳輸及字形路徑快取，網格獨立更新。

## 裝置與音訊

- 原曲原速播放；不量化，不加 swing。
- 聲音監聽預設 OFF、Master 40%；觸控效果深度 85%。
- 聲音效果在分析之後，避免效果尾巴製造新的分析事件。
- VST3／AU 是音訊效果 bay，預設 BYPASS，不必安裝第三方音源。
- Launchpad 接 `LPProMK3 MIDI`，進 Programmer Mode；型號與 layout 17 回覆都通過才送畫面。
- RGB SysEx 使用 `F0 00 20 29 02 0E 03`；只送變動的格子。8×8 pads 的 MIDI note 為 11–88，十位為列。
- [Novation 官方 Programmer Reference](https://fael-downloads-prod.focusrite.com/customer/prod/s3fs-public/downloads/LPP3_prog_ref_guide_200415.pdf)。

## 建置與版本

`npm run build` 從來源重建全部 `patchers/` 與 Max Project。不要直接修改生成檔。開發時 V8 autowatch 會重新初始化；正式驗證仍要重新開啟主 patch，確保 DSP 接線更新。

`npm test` 包含原有回歸、低頻 10,000 步與 1.1 參考的比對，以及事件／轉場／五行為測試。原始錄音與大型診斷只存在 `tmp/`，Git 與 ZIP 都排除它們。

完整量測及事件欄位、延遲、限制見 [事件引擎與轉場](事件引擎與轉場.md)。
